Later, pag okay na yung code, pwede nito na i brach sa github, then gawan niyo ng sariling name niyo para mai compare sa main para sync.

ito yung steps pag i-uupload niyo yung gawa niyo

Step 1: Kunin ang latest files. Bago mag-code, make sure updated ang local repo niyo sa bagong React structure.

>   git checkout main
>   git pull origin main


Step 2: Gumawa ng sariling branch. Wag mag-code sa main branch. Gumawa ng sariling branch na naka-pangalan sa task niyo.

>   git checkout -b name-<task> (e.g., git checkout -b riza-results-matrix)


Step 3: Stage and Commit. Kapag tapos na ang Tailwind layout at walang error sa JSX, i-commit.

>   git add .
>   git commit -m "UI: Converted [Page/Component] to Tailwind"       required may "" laman dito sa loob ng double quotation mark.

Step 4: Push and PR. I-push ang sariling branch at gumawa ng Pull Request (PR) sa GitHub. Wag niyo i-merge, ako ang mag-rereview at mag-a-approve.

>    git push origin <branch-name> (e.g. git push origin aleina-core-components)


(Note: Mag-attach ng screenshot ng finished screen niyo sa PR para makita ko agad kung nasunod ang design).
